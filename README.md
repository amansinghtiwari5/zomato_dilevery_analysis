# 🍔 Zomato Delivery Performance Analysis

## 📌 Project Overview
Food delivery platforms face challenges such as delivery delays, traffic congestion, and fluctuating customer satisfaction.  
This project analyzes **Zomato delivery operations data** to identify the key factors affecting delivery time and overall performance, and to provide actionable business insights.

The project demonstrates an **end-to-end data analytics workflow**, from raw data cleaning to interactive dashboard creation.

---

## 🎯 Objectives
- Analyze delivery time patterns across cities
- Understand the impact of traffic, weather, and festivals on delivery delays
- Evaluate delivery partner performance using ratings
- Build an interactive dashboard for business decision-making

---

## 📂 Dataset
- **Source:** Kaggle – Zomato Delivery Operations Dataset  
- **Type:** Real-world food delivery operations data  
- **Contents include:**
  - Order details
  - Delivery time
  - City
  - Traffic conditions
  - Weather conditions
  - Delivery partner ratings
  - Festival indicators

> ⚠️ Note:  
> The repository contains a **sample dataset** for demonstration.  
> The full dataset can be accessed from Kaggle.

---

## 🛠️ Tools & Technologies Used
- **Python** (Pandas, NumPy, Matplotlib, Seaborn) – Data cleaning & EDA  
- **MySQL** – Data storage, SQL analysis, and data cleaning  
- **Tableau** – Interactive dashboard and visualization  
- **GitHub** – Version control and project hosting  

---

## 🔄 Project Workflow
1. **Data Cleaning (Python & MySQL)**
   - Handled missing values (NaN vs NULL)
   - Fixed data types and incorrect formats
   - Resolved real-world SQL issues (Error 1093, Error 1292)

2. **Exploratory Data Analysis (EDA)**
   - Delivery time distribution
   - Traffic and weather impact analysis
   - City-wise performance comparison
   - Festival vs non-festival delivery trends

3. **SQL Analysis**
   - City-level average delivery times
   - Impact of traffic density on delivery duration
   - Delivery partner rating vs performance
   - Peak delivery hours analysis

4. **Dashboard Development (Tableau)**
   - KPI cards for quick insights
   - Interactive charts and filters
   - Business-friendly visual storytelling

---

## 📊 Key Insights
- High traffic density significantly increases delivery time  
- Festival days show longer delivery durations due to surge demand  
- Certain cities consistently underperform compared to others  
- Peak delivery delays occur during evening hours  
- Higher-rated delivery partners tend to deliver faster  

---

## 💡 Business Recommendations
- Increase delivery partner availability during peak and festival hours  
- Improve ETA calculations in high-traffic zones  
- Assign experienced delivery partners to high-demand areas  
- Optimize city-wise delivery operations based on performance trends
